# Neon Ridge Defense

Автономная браузерная Tower Defense игра на HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` в любом современном браузере. Сервер, сборка и внешние зависимости не нужны.

## Управление

- Выберите тип башни справа и щелкните по свободной зоне карты.
- Щелкните по поставленной башне, чтобы улучшить или продать ее.
- `Старт` запускает следующую волну; несколько волн можно выпускать одновременно.
- `Пауза` останавливает симуляцию.
- Кнопка скорости переключает `x1`, `x2`, `x4`.
- Горячие клавиши: `1`-`5` выбирают башни, `Enter` запускает волну, `Space` ставит паузу.
